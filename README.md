# 선생님의 하루 (Teacher's Mind & Time)

> **초·중·고 교사를 위한 일과 맞춤형 마음챙김 타이머 & 할일 관리 웹 애플리케이션**

외부 서버 통신이나 복잡한 설치 과정 없이, 웹 브라우저(Chrome, Edge, Whale, Safari 등)에서 `index.html` 파일을 더블 클릭하기만 하면 즉시 작동하는 100% 로컬 독립형 단일 파일 웹 애플리케이션입니다.

---

## 🌟 주요 기능

### 1. 교직 맞춤형 원클릭 타이머 & 4-7-8 호흡 가이드
- **수업 전 3분 쉼**: 수업 시작 종이 울리기 전 교사의 마인드셋을 가다듬는 4-7-8 호흡 가이드 모드.
- **쉬는시간 10분 리프레시**: 쉬는 시간 동안 차분히 재충전할 수 있는 호흡 및 휴식 가이드.
- **학교급별 수업 타이머**:
  - 초등수업 40분
  - 중등수업 45분
  - 고등수업 50분
- **방과후 행정 25분**: 뽀모도로 기법 기반의 집중 공문 처리 모드.
- **정밀 드리프트 보정**: `Date.now()` 타임스탬프 델타 연산으로 브라우저 탭 비활성화 시에도 1초의 오차 없이 정확한 시간 측정.

### 2. 수업 및 교실 환경에 최적화된 알림 & 사운드
- **Web Audio API 기반 티베탄 싱잉볼 종소리**: 외부 오디오 파일 다운로드 없이 370Hz F#음과 배음(Harmonics)을 부드럽게 합성하여 교실에서 깜짝 놀라지 않는 청아한 소리 제공.
- **시각적 무음 알림 (Visual Flash)**: 조용한 자습 시간이나 교무실을 위한 무음 토글 지원. 종료 시 화면 테두리가 은은하게 펄스 발광.
- **전자칠판 전체화면 모드**: 단축키 `F` 또는 상단 ⛶ 버튼으로 학생들과 함께 보는 대형 타이머 모드 전환.

### 3. 교직 특화 할 일 (To-Do) 관리
- **3대 교직 영역 카테고리**: 수업 준비(초록), 행정 공문(파랑), 학생/학부모 상담(주황).
- **원클릭 빠른 템플릿**:
  - `[공문] 나이스 출결 마감`
  - `[수업] 수업 학습지 인쇄`
  - `[상담] 학부모 상담일지 정리`
  - `[행정] 가정통신문 발송 확인`
- **100% 로컬 브라우저 저장**: 학교 및 학생 개인정보 보호를 위해 서버 전송 없이 브라우저 `localStorage`에만 저장.

### 4. 교사 번아웃 방지 마음 챙김 일지 (Mindfulness Journal)
- **5단계 기분 체크인**: ☀️ 맑음, 🌿 차분함, ☕ 고단함, 🌧️ 지침, 🌙 휴식필요.
- **수업 후 칭찬 & 한 줄 회고**: 바쁜 하루 속에서 나를 격려하는 짧은 일지 작성 및 최근 히스토리 조회.
